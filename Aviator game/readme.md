# Aviator - Browser Version

A browser version of the virtual-credit Aviator game.

## Files

- `index.html` — page structure
- `style.css` — styling and responsive layout
- `game.js` — game logic, animation, jet, multiplier, cash-out and controls

## Run locally

Open `index.html` in Chrome.

## GitHub Pages

Upload `index.html`, `style.css`, and `game.js` to the repository root, then enable:

**Settings → Pages → Deploy from a branch → main → / (root)**

The game can then be opened through the GitHub Pages URL.

This is an educational virtual-credit simulation and does not involve real money.
